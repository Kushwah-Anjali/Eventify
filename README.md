# Eventify – Event Management System

Eventify is a full-stack web-based Event Management System designed to simplify event creation, registration, and management through a secure and role-based platform.

It allows users to discover events, register using OTP verification, upload required documents, and track event details. Event creators and admins can manage events through dedicated dashboards.

---

## Features

### User Features
- User registration with OTP email verification
- Browse and discover events
- Filter events by:
  - Upcoming
  - Today
  - Past
  - All
- Register for events online
- Upload required event documents
- View registration summary
- Receive email confirmation
- Contact admin through enquiry form
- View event locations using Google Maps

### Event Creator Features
- Personal event management dashboard
- Create and publish events
- AI-generated event descriptions using Groq AI
- Track event registrations
- Manage uploaded user documents
- Maintain post-event history
- Upload:
  - Photos
  - Videos
  - Budget details
  - Attendance records

### Admin Features
- Manage all events
- View registered users
- Add new events
- Pin event location on map
- Manage event dashboards

### Super Admin Features
- Manage admin accounts
- Create new admins
- Assign login credentials
- Role-based platform control
